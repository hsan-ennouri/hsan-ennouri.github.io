## About

I'm an Electrical and Electronics Engineering Master's student at EPFL, interested in embedded systems, signal processing, and bioelectronics. This portfolio presents a selection of my technical projects spanning PCB design, embedded firmware, wireless communications, computer vision, power electronics, and autonomous robotics.

## Projects

- **UNO Card Recognition:** Classical computer vision pipeline for UNO card detection and classification using HSV segmentation, morphological filtering, and normalised cross-correlation, no neural networks · *EPFL EE-558, 2025–2026*
- **DAB DC–DC Converter:** Full design cycle of a 50 W Dual Active Bridge converter: analytical sizing, magnetic component construction, Altium schematic and PCB, and DSP-based PI control with bench testing · *EPFL EE-365, 2025–2026*
- **Endovascular Sensor Readout:** Readout circuit redesign for a multi-sensor guidewire (CoroSense), custom PCB, STM32 migration · *EPFL MICROBS Lab, 2025*
- **Acoustic OFDM Transceiver:** Full OFDM system achieving 0% BER with Zero-Forcing channel estimation and Viterbi phase tracking in MATLAB · *EPFL EE-442, 2025–2026*
- **Biometric Smart Vault:** IoT-connected vault with ESP32 firmware and CATIA-designed enclosure · *NUS CS3237, 2024–2025*
- **Autonomous Navigation:** ROS 2 path planning and EKF-based drone state estimation in Gazebo · *NUS EE4308, 2024–2025*
- **Morse Code Translator:** Real-time translator in pure AVR Assembly with custom peripheral drivers · *EPFL EE-208, 2023–2024*
